# はじめに

本書は、Raspberry Pi 5の上で動くTRON系OS「TessronOS」の仕様書である。TessronOSの目的、構成、利用者とプログラムに提供する機能を、TessronOSを使う人、TessronOS上でプログラムを開発する人、TessronOS自体を開発する人に向けて説明する。

本書は仕様を網羅しない。各章では、その分野の設計方針と、外部から見える主な仕様を説明するにとどめる。関数の引数や構造体の詳細はヘッダファイル(`include/`)が一次資料であり、本書と食い違う場合はヘッダとソースコードが正しい。

### 読み方

第1章で全体像を、第2章でレイヤ構成とソースツリーを把握してから、関心のある章へ進むとよい。第3章から第9章はOSの内部(動作環境、カーネル、プロセス、デバイス、ファイルシステム、実身、ネットワーク)、第10章と第11章は画面と利用者から見える部分、第12章は開発と試験の手順である。付録Aにシステムコールの一覧、付録Bに用語をまとめた。

### 表記

- 数値は10進数で書く。アドレスとビット列は`0x200000`のように16進数で書く。サイズのKB、MB、GBは2のべき乗である。
- 関数名、ファイル名、コマンドは`tk_cre_tsk`、`build_make/makefile`のように等幅フォントで書く。ソースのパスはリポジトリのルートからの相対パスで書く。
- 実身、仮身、原紙、小物などBTRONの用語はそのまま用いる。初めての人は付録Bを参照してほしい。
- プロセッサは、SMP T-Kernel仕様に合わせて1から数えるプロセッサID(PRC1〜PRC4)と、0から数えるCPU番号(CPU0〜CPU3)を区別する。PRC(n)はCPU(n-1)である。

### 本書の範囲

本書が説明するのは、2026年9月末時点のソースコードの実装である。記載した機能は動作するものであり、計画段階のものは「計画」と明記する。実機(Raspberry Pi 5)で確認したことと、QEMUでしか確認していないことは、第3章で区別する。
