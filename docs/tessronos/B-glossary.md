# 付録B　用語

| 用語 | 意味 |
| --- | --- |
| 実身 | UUIDで識別され、レコードの列、属性、保護情報を持つもの。ファイル、共有メモリ、デバイス、プロセス、通信路、ウインドウがすべて実身である |
| 仮身 | 実身を指すもの。xmlTADの`<link>`要素で、参照先の実身のUUIDと表示形式を持つ |
| 実身キー | 実身を開いて得るハンドル。所有プロセスと許可された操作を記録している |
| レコード | 実身の内容の単位。型(0〜31)とサブタイプを持つバイト列 |
| 管理用セグメント | 実身の名前、日時、保護情報、アプリケーションの設定を持つJSON |
| 参照数 | 実身を指している仮身の数。TSFSが仮身表から数える |
| 屑実身 | 参照数が0になった実身 |
| キャビネット | 仮身を並べた実身。ディレクトリの代わりになる |
| 原紙 | 新しい実身を作るときの元になる実身。原紙箱に並ぶ |
| 小物 | 独自のデータを持たないプログラム。小物箱から起動する |
| 定義実身 | メニューやパネルの定義をxmlTADで持つ実身 |
| データボックス | パネルの定義を番号付きで持つ実身。BTRONのデータボックスを実身にしたもの |
| 部品 | ウインドウ内のスイッチ、セレクタ、テキストボックスなどの操作の単位。カーネルが描画する |
| パネル | 部品を並べたもの。データボックスの定義から作成する |
| 外観設定テーブル | 色、パターン、長さ、時間、設定値を番号で参照するテーブル |
| xmlTAD | TRON Application DatabusをXMLで表現したもの。文章、図形、仮身を持つ |
| TSFS | TessronOSのネイティブのファイルシステム。実身をそのままディスクに格納する |
| 中心核、周辺核、外核 | BTRONのレイヤ構成におけるカーネルの3つのレイヤ。第2章 |
| 保護レベル | タスクの特権レベル。0と1がEL1、2と3がEL0 |
| プロセス | 固有のアドレス空間を持ち、EL0で動くプログラムの実行単位 |
| テキスト入力ポート | キー入力をかな漢字変換へ渡すインタフェース |
| メッセージ行 | 画面下端の行。入力モード、時刻、短いメッセージを表示する |
| トレー | プログラム間で仮身や文字列を受け渡すための一時的な保管場所(クリップボード) |
| パッケージ(.tpk) | アプリケーションのプログラム実身と原紙の実身を1つにまとめた配布用のファイル。第11章 |
| rumpカーネル | NetBSDのカーネルのコードを、ホストが用意するハイパーコールの上で動く部品として使う仕組み。TessronOSはこれでNetBSDのTCP/IPスタックをカーネルの中で動かす。第9章 |
| ハイパーコール | rumpカーネルがホストに対して呼ぶ関数(`rumpuser_`)。メモリ、スレッド、ロック、時計などを受け持つ。TessronOSでは`peripheral_kernel/network/netbsd/rumpuser.c` |
